# 캐릭터 에셋 사양서 (직접 그릴 때 참고)

보글하우스 마스코트를 게임에 이식하기 위해 필요한 그림 목록과 규격.
전부 그려서 주시면 코드(현재 canvas 직접 그리기)를 이미지 스프라이트로 교체해 연결한다.

관련 코드: `src/characters.js`(조각 얼굴) · `src/main.js`(팝업/등급 화면)

---

## 공통 규격 (모든 에셋)

- **포맷**: PNG-24 + 투명 배경(알파). 손그림 크레용 질감이면 PNG가 맞다. 벡터(SVG)로 뽑을 수 있으면 그게 더 좋음(어느 크기든 선명).
- **색공간**: sRGB.
- **배경**: 완전 투명. 그림자·테두리 박스 넣지 말 것(게임이 피자 위/카드 위에 얹음).
- **선 색**: 마스코트 하늘색 계열(현재 코드값 `#37A9DF`). 원본 로고 파란색 그대로면 됨 — 정확한 HEX 하나 알려주면 그 값으로 통일한다.
- **여백**: 캔버스 가장자리에 그림이 닿지 않게 사방 여백 조금.
- **같은 세트는 캔버스 크기·등록점(아래 '정렬 기준')을 동일하게** — 표정만 바뀌고 위치는 안 흔들려야 자연스럽게 교체된다.

---

## A. 조각 위 리액션 얼굴 — 4종 (필수)

피자를 자르면 **조각마다** 손님 얼굴이 뿅 뜬다. 조각 개수만큼(최대 8개) 동시에 뜨므로
**머리+고깔모자까지의 '반신(bust)'** 정도로 단순하게. 몸통은 넣지 말 것(작아서 뭉갬).

- **화면 실제 크기**: 지름 약 60px(폰 기준, 레티나 2배 → 실제 120px 안팎). 위 고깔까지 포함하면 세로가 더 김.
- **권장 제작 크기**: **정사각 512 × 512px** (게임에서 축소해 쓰므로 항상 선명). 벡터면 크기 무관.
- **정렬 기준(중요)**: 4장 모두 아래 배치를 지켜주세요. 그래야 표정만 바뀌고 머리 위치가 안 흔들림.
  - 얼굴(머리) **중심** = 캔버스 좌우 정중앙, 세로로는 **위에서 62% 지점**
  - 얼굴 **지름** = 캔버스 폭의 약 46% (512 기준 ≈ 236px)
  - 고깔모자는 그 위 여백(위 38%)에 들어가게

```
  ┌───────── 512 ─────────┐
  │        △ 모자          │  ← 위쪽 38%: 고깔모자 자리
  │       (줄무늬)         │
  │      ●     ●          │
  │   (  얼굴 ○ 중심 )     │  ← 세로 62% 지점 = 얼굴 중심
  │        \_/            │
  │                       │  ← 아래 여백
  └───────────────────────┘
```

### 표정 4종 (파일명 → 감정 → 지금 코드 근거)

| 파일명           | 언제 뜨나                            | 표정                                  |
| ---------------- | ------------------------------------ | ------------------------------------- |
| `face-smug.png`  | 남보다 많이 받은 손님(제 몫의 110%+) | 반달 눈 + 능글맞은 큰 웃음 😏         |
| `face-happy.png` | 딱 제 몫 받은 손님(95~110%)          | 기분 좋은 미소 🙂 (기본·가장 자주 뜸) |
| `face-meh.png`   | 조금 손해(80~95%)                    | 한쪽 눈썹 올림 + 애매한 입 🤨         |
| `face-shock.png` | 크게 손해(80% 미만)                  | 부릅뜬 눈 + 벌린 입 😱                |

> 4장 모두 **같은 고깔모자**를 쓰고 표정(눈·입)만 다르면 통일감이 좋다.
> 손님별 색 구분은 지금도 미미해서 없어져도 무방(마스코트가 단색이라 오히려 자연스러움).

---

## B. 큰 마스코트 포즈 — 3종 (등급 결과 화면용)

게임 끝 **등급 화면**(`완벽해요 / 그럭저럭 / 다시 한 번`)에 전신 마스코트가 결과에 맞는 포즈로 등장.
여긴 공간이 넓으니 **머리+줄무늬 몸통+팔 포즈까지 전신**으로.

- **화면 실제 크기**: 세로 약 200px(레티나 → 실제 400~600px).
- **권장 제작 크기**: 세로로 긴 **700 × 900px** 정도(전신 여유). 벡터면 무관.
- **정렬**: 3장 모두 캔버스 안에서 발 밑선·중심축을 맞춰주세요(포즈 바꿔도 안 흔들리게).

| 파일명             | 등급              | 포즈                          |
| ------------------ | ----------------- | ----------------------------- |
| `mascot-great.png` | 완벽해요 (505점+) | 만세 + ✌️ 브이 (원본 그 느낌) |
| `mascot-ok.png`    | 그럭저럭 (330점+) | 한쪽 어깨 으쓱, 애매한 웃음   |
| `mascot-fail.png`  | 다시 한 번 (0점+) | 땀 흘리며 갸웃 / 시무룩 💦    |

---

## C. (선택) 라운드 점수 팝업

라운드마다 뜨는 작은 점수 카드(`탭해서 계속`). 여긴 좁아서 **A의 얼굴 스프라이트를 재활용**하면 됨
(그 라운드 제일 억울한 손님 표정). 새 그림 필요 없음 — 원하면 여기용 미니 포즈를 따로 줘도 되고.

---

## 정리 — 최소 필요 목록

**꼭 필요:** A 4장(`face-smug/happy/meh/shock`) + B 3장(`mascot-great/ok/fail`) = **총 7장**

넘겨줄 때

1. 파일은 `assets/mascot/` 폴더에 위 파일명으로 넣거나, 압축해서 전달.
2. **선 색 HEX 하나** 확정해서 알려주기(코드 톤 통일용).
3. 주면 `src/characters.js`·`src/main.js`를 이미지 방식으로 교체하고 모바일에서 확인까지 진행.
