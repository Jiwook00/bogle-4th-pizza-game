# 손님 표정 & 결과 멘트 규칙

피자를 자른 뒤, 손님 캐릭터들의 **표정**과 결과 화면 **멘트**가 어떤 조건에서 어떻게 결정되는지 정리한 문서.
표정과 멘트는 서로 **독립된 두 시스템**이다.

관련 코드

- 표정 판정: `src/scoring.js` → `faceFor()`
- 표정 그리기: `src/characters.js` → `drawFace()`
- 조각별 표정 배치: `src/game.js` (`reactions` 생성)
- 결과 멘트: `src/main.js` → `showRoundScore()` / `statusComment()`
- 점수 상수: `src/config.js`

---

## 1. 손님 얼굴 표정 (조각마다 개별)

각 조각의 **`share`** 값으로 표정이 결정된다.

- `share = (그 조각 면적) ÷ (공정 몫)`
- `공정 몫 = (전체 피자 면적) ÷ (주문 개수)`
- 즉 `share = 1.0` 이면 "딱 제 몫만큼 받은" 조각

| 조건 (share)         | 표정 키   | 얼굴 모양                  | 감정                     |
| -------------------- | --------- | -------------------------- | ------------------------ |
| `share ≥ 1.1`        | `smug`    | 반달 눈 + 능글 웃음        | 남보다 많이 받아 흡족 😏 |
| `0.95 ≤ share < 1.1` | `content` | 점 두 눈 + **잔잔한 미소** | 제 몫 받아 만족 🙂       |
| `0.8 ≤ share < 0.95` | `brow`    | 한쪽 눈썹 올림 + 애매한 입 | 좀 적네…? 🤨             |
| `share < 0.8`        | `shock`   | 부릅뜬 눈 + 벌린 입        | 확 손해 봤다 😱          |

> 손님이 8명이면 8개 조각이 각자 자기 `share`로 표정을 짓는다. 공평하게 자를수록 모두 `content`(미소) 쪽으로 수렴한다.

## 2. 결과 화면 멘트 (라운드당 한 줄)

우선순위: **상태 멘트(`statusComment`)가 있으면 그것을 먼저 표시**, 없으면(`ok`) **가장 억울한 손님(최소 share) 표정 기반 멘트**를 표시한다.

### 2-a. 상태 멘트 (우선 — 있으면 표정 멘트를 덮음)

> 부스러기(전체 면적의 2% 미만, `SCORE.crumbRatio`) 조각은 개수 `n`에 세지 않는다.

| 상태      | 조건                                             | 멘트                               | 채점 영향                      |
| --------- | ------------------------------------------------ | ---------------------------------- | ------------------------------ |
| `over`    | `n > 주문 수`                                    | "너무 많이 잘랐어! 공평도 반토막." | 공평도 ×0.5 (`overcutPenalty`) |
| `timeout` | `n < 주문 수` **AND** 시간 초과(`remaining ≤ 0`) | "손님이 그냥 가버렸습니다."        | 공평도 ×(n/주문) 비례 감점     |
| `short`   | `n < 주문 수` **AND** 시간 남음                  | "조각이 모자라잖아."               | 공평도 ×(n/주문) 비례 감점     |
| `ok`      | `n == 주문 수`                                   | (상태 멘트 없음 → 2-b로)           | —                              |

### 2-b. 표정 멘트 (`ok`일 때 — 최소 share 손님 기준)

주문 개수를 정확히 맞췄을 때, **가장 손해 본 조각(최소 share)**의 표정으로 멘트를 고른다.

| 최소 share 손님 표정 | 멘트                          |
| -------------------- | ----------------------------- |
| `smug`               | "흡족한 표정이야."            |
| `content`            | "다들 조용하네."              |
| `brow`               | "누가 눈썹을 올렸어."         |
| `shock`              | "한 명이 자기 조각을 노려봐." |

## 3. 연습(튜토리얼) 라운드 코치 멘트

실전이 아닌 연습 라운드는 위 시스템과 별개로 `coachOutro` 대사를 사용한다 (`src/main.js` → `playCoachOutro()`).

| 조건                            | 사용 대사           |
| ------------------------------- | ------------------- |
| `n < 주문 수`                   | `coachOutro.short`  |
| `n > 주문 수`                   | `coachOutro.over`   |
| 공평도 `< unevenThreshold`(75%) | `coachOutro.uneven` |
| 그 외(잘 함)                    | `coachOutro.good`   |

---

## 요약

- **표정**: 조각별 `share` 4단계로 개별 결정. 남보다 많으면 흡족(`smug`), 제 몫이면 미소(`content`), 조금 적으면 눈썹(`brow`), 크게 손해면 충격(`shock`).
- **결과 멘트**: 실수 상태(`over`/`short`/`timeout`)가 있으면 그 멘트를, 없으면 가장 억울한 손님 표정 멘트를 표시.
